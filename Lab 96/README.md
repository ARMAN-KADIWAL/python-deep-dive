# Lab 96 — Improved Error Messages

Eight demonstrations of IndexError, TypeError, ValueError, nested tracebacks, error context, version comparison, custom exceptions and exception inheritance. Run each with `python3 filename.py`; run `python3 -m unittest -v test_error_messages.py` to test error handling.

The supplied material ends during Task 4.2. Its missing ending and unit tests are reconstructed. The repository retains the more detailed supplied examples with corrections (string repetition, actual tracebacks, exception ordering, custom validation messages, API context) rather than the condensed terminal walkthrough. Run the version comparison script with both Python 3.12 and 3.13 only if both are installed; no version-specific enhancements are claimed without comparison. Database and banking operations are simulations.
