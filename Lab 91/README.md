# Lab 91: Common Design Patterns in Python

Practice Singleton, Factory and Observer patterns using Python 3.8+ and the standard library.

Run the eight scripts individually using `python3 <filename>`. For the interactive factory, enter `quit` at the vehicle prompt to exit. For `design_patterns_demo.py`, choose 5 to exit.

The supplied material ended inside the interactive demo; its remaining menu branches were reconstructed. All eight scripts were executed successfully in a Linux test environment; this is not exhaustive thread-safety verification. Database and trading examples are simulations.
