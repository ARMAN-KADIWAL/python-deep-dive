# Lab 55: Handling CSV Data - Reading and Writing CSV Files

## Objectives
- Read CSV data with Python's built-in csv module.
- Write and append CSV records using csv.writer().
- Filter CSV data with simple and multiple conditions.
- Read and write CSV data as dictionaries.
- Add, update, delete, search, report, and export dictionary-backed CSV records.
- Handle file and CSV parsing errors.

## Requirements
Python 3.x. Standard library only.

## Files
- students.csv: sample student records.
- read_csv_basic.py: read and display CSV rows.
- read_csv_enhanced.py: access named columns and display student details.
- write_csv_basic.py: write product rows and read them back.
- write_csv_advanced.py: custom delimiter/quoting support and CSV append.
- filter_csv_data.py: filter rows by a selected column/value.
- advanced_filter.py: filtering with =, !=, >, <, >=, <=, and contains.
- csv_dict_operations.py: DictReader, DictWriter, grouping, average age, and honor students.
- advanced_dict_csv.py: CSV dictionary manager with load, save, add, update, delete, search, report, and JSON export.
- test_csv_lab.py: automated tests.

## Run the lab
Run commands from inside the Lab 55 folder:

    python3 read_csv_basic.py
    python3 read_csv_enhanced.py
    python3 write_csv_basic.py
    python3 write_csv_advanced.py
    python3 filter_csv_data.py
    python3 advanced_filter.py
    python3 csv_dict_operations.py
    python3 advanced_dict_csv.py

## Run automated tests

    python3 -m unittest -v
