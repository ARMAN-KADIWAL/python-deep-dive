## Getting started

Use a Python version compatible with the selected lab. Most earlier examples run on Python 3.8+; some later labs require Python 3.11–3.13. On an approved development environment:

```bash
git clone https://github.com/ARMAN-KADIWAL/python-deep-dive.git
cd python-deep-dive
cd "Lab 84"
python3 test_restful_api.py
```

For labs with external dependencies, create an isolated environment and install only that lab's requirements. For example, from the repository root:

```bash
cd "Lab 100"
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest tests/ -v
python -m src.app
```

Open `http://127.0.0.1:5000` for the local capstone demonstration. In Windows PowerShell, activate the environment with `.venv\Scripts\Activate.ps1`. Follow each lab's README for exact commands and prerequisites.

## Scope and limitations

Several supplied handouts ended mid-code; missing sections were independently reconstructed and documented. Public HTTP examples require permitted network access. Lab 97's experimental native JIT comparison requires a suitably compiled CPython interpreter and has not been verified on the original lab environment. The capstone is a local educational demonstration; public deployment, production security hardening and load testing are not claimed. Simulated operations do not represent real service delivery.

This repository preserves the learning work and its documented verification as a reference portfolio.
